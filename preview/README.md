# C Scale — versão alternativa hospedada em GitHub Pages

Compilação alternativa da interface mais recente do C Scale, para uso enquanto o Railway não aceita novos builds.

**Não substitui o servidor Next.js**. O login Supabase e as telas que usam RLS permanecem operacionais, mas o pareamento WhatsApp por QR Code não funciona nesta hospedagem estática. O serviço privado do WhatsApp permanece no Railway; não disponibilize sua chave de gateway no navegador ou repositório.

O endereço esperado, após GitHub Pages ser habilitado, é `https://iblsmusicsorocaba-afk.github.io/Cscale/`.

Configurações de redirecionamento do Supabase Auth podem precisar incluir este domínio para e-mails de confirmação e recuperação.
